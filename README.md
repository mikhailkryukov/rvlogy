# rvlogy.com

Website for **RVlogy: RV Travel Map**, the iOS app by Crystal RV Rentals.

- `/` home page
- `/support/` support (App Store support URL)
- `/privacy/` privacy policy (App Store privacy URL)
- `/data/` OpenStreetMap-based stop database under ODbL (`rvlogy-data.zip`, rebuild with `data/export_odbl.py` in the app project)

Plain static HTML/CSS, served by GitHub Pages with the custom domain in `CNAME`.
